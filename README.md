# Motion Detection
This project demonstrates a motion detection system using a webcam. It highlights areas of movement by drawing red rectangles on a video stream.

## Features
- Accesses the user's webcam in real-time.
- Detects motion by comparing frames.
- Draws red rectangles around areas with detected motion.
## Technologies Used
- HTML5
- JavaScript
- `<video>` and `<canvas>` APIs
- Webcam access via `navigator.mediaDevices.getUserMedia`

  ## How to Use
 - Clone the repository to your local machine:
    ```
    git clone https://github.com/ultimatrix2/Motion_detection.git
    ```
 - Open the index.html file in a web browser.
